## 非常重要的限制
- 網站為規劃表，**沒有自動訂位、也不會即時監控營業時間**。
- 所有 2027 年指定日期的商家營業、課程場次、價格與訂位狀態都需要再跟店家核對。
- 勾選紀錄只儲存在使用者當前的瀏覽器 localStorage，不能跨裝置同步，也不會真的送出訂位。
- 部分網站連結指向供應商官方網站、預約平台，應由旅客自行核對條款。
- 餐廳不安排餐餐米其林，保留自由用餐與休息時間。
- 2/6 恰逢農曆春節；週末市集和餐廳可能調整營業。
